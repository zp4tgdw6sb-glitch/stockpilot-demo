StockPilot דמו לאייפון (GitHub Pages)

1. פתח חשבון GitHub חינמי.
2. צור Repository ציבורי חדש בשם stockpilot-demo. אל תעלה קובצי שרת, סיסמאות או נתוני מחסן.
3. העלה לתיקיית השורש של המאגר את כל הקבצים שבתיקייה הזו (לא את קובץ ה-ZIP עצמו).
4. תחת Settings > Pages, בחר Deploy from a branch, ענף main, תיקייה /(root), ושמור.
5. המתן לפרסום. כתובת האתר תופיע תחת Pages, לרוב https://USERNAME.github.io/stockpilot-demo/
6. פתח את הכתובת ב-Safari באייפון, שיתוף > הוסף למסך הבית.

זוהי הדגמה מקומית בלבד. נתונים נשמרים ב-localStorage של המכשיר, ללא גיבוי או סנכרון, ועלולים להימחק. אין להכניס מידע אמיתי או סודי.
